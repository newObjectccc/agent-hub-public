# Codex 可靠性与权限收尾验收（2026-10-21）

本批修复历史请求覆盖乱序完成回复、手机权限提示未接线、权限覆盖未校验实际基线，以及进程停止失败时过早释放互斥状态。生产代码、文档与证据分别记录；真实审批闭环仍待验，未把模拟结果标成真机结果。

## 消息对账

接收版本决定 GET 期间到达的消息是否需要保留，创建时间只决定排序。创建早、完成晚的回复，即使时间早于快照末尾，也不能被当作“权威已删”。压缩后新请求重新建立版本基线。纯逻辑回归与真实浏览器受控乱序场景均验证回复保留。

## 实际权限

详情、attach 响应与 WS 同步实际策略，接管期间持续显示。never 明确不请求操作审批；on-request 说明只在模型申请时询问；untrusted 说明需要确认的操作会询问；缺失回显显示未知。退出/重新接管不沿用上一进程策略。文件访问范围与审批独立呈现，danger-full-access 不等于关闭审批。

显式覆盖先恢复继承设置、取得协议回显，拒绝放宽或未知策略。需要收紧时确认旧 writer 退出，以新进程应用参数，并比较最终回显；网络、可写根目录与临时目录不能附带放宽。仅接受已有可写根，避免把新增符号链接子路径误判为安全子集。等待释放期间仍 busy；kill 报错不能冒充进程已退出。
