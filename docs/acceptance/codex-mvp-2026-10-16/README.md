- 连续两轮使用相同原生审批 ID，第一轮拒绝得到 BLOCKED，第二轮仍显示独立卡片；刷新后卡片与两条相同文本的独立用户消息均保留。允许后得到 CREATED，文件内容校验通过、未决卡片为零、等待状态结束。
